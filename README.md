# 小朋友複習小書

依年級、科目、單元整理的複習重點與練習題網站。內容和程式分開：要新增內容，只要把單元檔放進 `data/年級/科目/`，推上 GitHub 後網站就會自動更新。

- 怎麼新增內容：看 [資料格式說明.md](資料格式說明.md)
- 網站設定（年級與科目順序、模擬考配題）：`data/config.json`
- 格式檢查與目錄產生：`node tools/build-index.mjs`

## 網站功能

- 選年級、科目，看各單元的重點整理（讀重點）
- 依單元範圍與題型練習，或照考卷配題做一回模擬考（做練習）
- 錯題自動記在這台裝置，可以只練錯題
- 知識島冒險（`adventure.html`）：每個有題目的單元是地圖上的一關，期中、期末各一條路線，最後是混合各單元的大魔王。答對攻擊怪獸、答錯扣愛心並看解說，過關得星星，並從該單元的重點複習抽一張知識卡放進寶物袋。新增單元檔就會自動多一關；答錯的題目也會進錯題本

## 目前內容

整合了兩份原創題庫：Claude「期中練功房」與 GPT「複習小書」（2026-11-02 匯出）。

- 國語（南一）三、四年級上學期：第 1–12 課、語文天地一至四、閱讀搶先報一至四（依期中／期末分開），另有補充閱讀篇章；每課有生字、語詞、同音／形近／多音字、理解問答等重點整理
- 自然（康軒）：三、四年級各第 1–2 單元
- 社會（翰林）：三年級第 1–2 單元、四年級第 1–3 單元

題目為依課程原創的練習題，不是學校正式考卷；實際考試範圍以老師公告為準。
